💳 페이앱 자동결제 연결

한 번만 연결하면 대표와 CS 직원 모두 고객을 검색한 뒤 금액을 다시 입력하지 않고 페이앱 결제링크를 만들 수 있습니다.

연동 KEY/VALUE는 Script Properties에 저장하며 저장 후 화면에 다시 표시하지 않습니다. CS 직원에게는 설정칸이 보이지 않습니다.

🔵 토스페이먼츠 연결 선택사항

아직 가입 전이면 비워두셔도 됩니다. 페이앱은 그대로 작동합니다. 토스 가입 후 테스트 키를 저장하면 CS 화면에 토스 결제링크 버튼이 자동으로 나타납니다.

V2 주문서형/결제창형 연동 키(gck/gsk)를 사용합니다. 시크릿 키는 Script Properties에만 저장되고 GitHub·고객 화면에는 노출되지 않습니다.
비밀번호는 평문으로 저장하지 않고 해시값으로 보관합니다. 기존 첫 로그인 비밀번호를 사용 중이면 먼저 새 비밀번호로 변경하세요.
